# ooDaiden

Personal portfolio website built with HTML, CSS, and Vanilla JavaScript. Features an interactive 3D canvas element (`cube.js`).

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Custom styling and layout
- **JavaScript (ES6+)** – Interactive 3D canvas logic
- **Cloudflare Pages** – Hosting and deployment

## 🚀 Local Development

No build steps or package installations are required.

1. Clone the repository:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/oodaiden.git](https://github.com/YOUR-USERNAME/oodaiden.git)
   ```
2. Navigate into the directory:

```bash
cd oodaiden
```

3.  Open index.html in your browser (or use VS Code's Live Server extension).
    📂 Project Structure
    oodaiden/
    ├── images/ # Static image assets
    ├── cube.js # 3D canvas animation script
    ├── index.html # Main entry point
    └── style.css # Global styles
